# Code of Conduct

## Our Pledge

We are committed to making participation in this project a
harassment-free experience for everyone, regardless of level of
experience, gender identity and expression, sexual orientation,
disability, personal appearance, body size, race, caste, ethnicity,
nationality, religion, or age.

## Enforcement

We do not enforce this code with an honor committee. We enforce it with
a maintainer (see `CODEOWNERS`). If you have an incident, report it to
`lm203688@users.noreply.github.com`.

Guidelines in force: [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Behavior that will not be tolerated

- Threats of violence, or physical/intellectual harassment, in any channel
  touching this project (issues, PRs, Discord if we ever stand one up).
- Revealing personal information without explicit consent.
- Sexually-violent or harassing imagery or language.
- Sustained disruption of technical discussion.

## Where to complain

1. Open an issue labeled `conduct` — visible but reviewable.
2. Email the maintainer privately for anything involving a named person.

We will remove the offending content, mute the offender, and — where
the incident warrants — suspend or ban the account.
