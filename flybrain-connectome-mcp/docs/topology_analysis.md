## 二、三个严重问题

### 1. 极度稀疏 — 与真实连接组差 1000 倍

C1 平均度 ~0.85，真实果蝇连接组平均 fanout ~745。这不是"缩放"问题，而是**结构哲学不同**：
- 真实连接组：每个神经元平均连 745 个（高度互联）
- C1 生成器：每个 agent 平均连 0.85 个（近乎星型 + 稀疏随机）

原因：reservoir 边固定 25% 概率 + 只连一个随机目标。真实连接组的 fanout 分布是：101-1000 占 49%，1001-10000 占 46%。

### 2. 聚类系数极低 — 缺失"小世界"特征

C1 聚类 0.04-0.11，真实大脑应在 0.3-0.6（小世界网络的典型范围）。原因：reservoir 边是纯随机连接，没有偏好性地连接到"邻居的邻居"。

### 3. 枢纽单点故障 — 移除 coordinator 网络崩塌

移除最高介数节点后，只有 7-34% 的节点仍连通。coordinator 是唯一跨模块桥梁，移除即断网。真实大脑有冗余抑制通路，不会因单神经元死亡而瘫痪。

## 三、设计空间现状

当前可参数化维度只有 3 个：

| 参数 | 范围 | 当前默认 |
|---|---|---|
| n_modules | 2-20 | 4 |
| agents_per_module | 3-25 | 6 |
| recurrent_pct | 0.1-0.4 | 0.287 |

**硬编码不可调的规则：**
- reservoir 密度固定 25%
- 抑制边只从 coordinator 发出（单枢纽）
- 边权 uniform 随机（非幂律）
- 3 个 motif 全部启用（不可关）
- 所有模块同质（无功能分化）
- 层级只有 3 层（cell → rep → coordinator）

## 四、真实连接组给出的扩展方向

从 motif 引擎抽取的真实数据中，有三个被当前生成器**浪费掉**的维度：

### A. 扇出分布（fanout_distribution）

真实数据记录了 5 个桶的神经元数量：
- 1-10: 0.79%（极少）
- 11-100: 1.34%
- 101-1000: **49.36%**（主导）
- 1001-10000: **45.51%**
- 10000+: 2.38%（极端枢纽）

当前生成器完全没用到这个分布 — 所有 agent 度数相同。应该**按这个分布采样每个 agent 的出度**。

### B. 功能分区（module specialization）

真实连接组的 superclass 分布暗示了功能分区：
- `cb_intrinsic`（蘑菇体内部）：28.74% 自递归 → **记忆模块**
- `ol_intrinsic`（嗅觉内部）：28.74% 自递归 → **感知模块**
- `vnc_intrinsic`（视觉无脑叶）：8.89% 自递归 → **运动模块**
- `visual_projection`（视觉投射）：1.3% 自递归 → **输入模块**

当前生成器所有模块一模一样。应该让**每个模块有不同的 motif 配置**。

### C. 抑制分布（distributed inhibition）

真实 APL 不是唯一抑制源 — 有大量 GABAergic 神经元分布在各级。当前生成器只有 coordinator 一个抑制源。应该**在多级添加抑制**。

## 五、建议的扩展（按 ROI 排序）

### P0：模块功能特化（最高 ROI）

```python
# 新增参数
module_profiles = {
    "sensory":    {"reservoir_density": 0.5, "recurrent_pct": 0.1, "inhibitory": False},
    "memory":     {"reservoir_density": 0.2, "recurrent_pct": 0.4, "inhibitory": False},
    "motor":      {"reservoir_density": 0.1, "recurrent_pct": 0.1, "inhibitory": True},
    "integration":{"reservoir_density": 0.3, "recurrent_pct": 0.2, "inhibitory": True},
}
```

每个模块按 profile 配置 motif 参数，打破同质性。

### P1：幂律扇出采样

从真实 fanout_distribution 采样每个 agent 的出度，而非固定 25% 随机。

### P1：多级抑制

在 coordinator 之外，让部分 tissue_rep 也发出抑制边（模拟分布式 GABAergic 网络）。

### P2：层级深度

从 3 层扩展为 4-5 层：coordinator → domain → module_rep → cell。

### P2：时间动力学

为 reservoir 边添加延迟权重，支持 echo-state 计算。

## 六、结论

当前 C1 生成器是一个**结构模板生成器**，不是**功能形态生成器**。它能在指定节点数下生成合法的 agent 拓扑图，但缺乏：
1. 网络科学特征（聚类、效率、度分布）
2. 功能分区（所有模块同质）
3. 生物真实性（浪费了 motif 引擎提供的 fanout 分布）

最有价值的下一步是 **P0 模块功能特化** — 只需改 `design_organism()` 一个函数，就能让生成器从"星型稀疏图"变成"功能分区的多模态网络"。
