## 三、G3 为什么不通——本轮最重要的战略判断

**G3 不是"再多跑几个实验"能解决的问题。** v2.74.0 把它的原因收敛到了基底层面：

1. **PR-2 三尺度全 FAIL，且效应不随 n 增长**
   composite 命中率 38.9% (n=10) → 71.4% (n=50) → **59.1% (n=100)**。
   三尺度 |mean_delta| ≤ 0.0005，比隔离度量可分辨的最小效应小一个数量级。
   → **缺陷是效应量，不是样本量。继续扩 n 不会翻案。**

2. **候选的替代度量被证明是同义反复（PR-2b 预执行拒绝）**
   `recovery_AUC = mean_t(r(t)) / drop_magnitude`，其 R-a 调节器 `= 1 − bridge_fraction − 0.5·ap_fraction`。
   即 `recovery_AUC` **同时**是 `bridge_fraction` 的单调函数、**且**被 PR-2 本身测量的量归一化。
   伪影率 95.2%（20/21 桥边删除后 `recovery_AUC` 上升——"切断系统"时报告"恢复能力上升"= 分母伪影），
   对照臂 85.7% 反向；双臂合并后 |corr| = 0.902（合并样本方差是规则指定样本的 4.94×，耦合被确认）。
   → **现有度量族内没有独立的第二读数。**

3. **因此 L4 是一个基底上限，不是工作量问题**
   要突破需要一个**不由 `bridge_fraction` 派生**的后果量（例如真实动力学下的功能读出），
   这超出当前项目的计算基底。**这不是"没努力够"。**

**战略含义**：G3 的解锁路径**不在现有度量族内**。
继续在 `drop_magnitude` 家族的谱系图上寻找新变体，只会反复得到同义反复——
PR-2b 的价值恰恰在于**在没有跑实验的情况下就否掉了这条路**，节省的是若干轮注定失败的扩样。
