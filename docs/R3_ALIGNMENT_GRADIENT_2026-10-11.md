**目的**：回答 R3 核心问题——结构增益是否随对齐度变化？是否存在阈值 a*？

---

## 一句话结论

**增益非单调：峰值在 a=0.50（混合对齐度），a=1.0（纯 evidence）并非最优。但 N=6/cell 远不够统计显著——"阈值"很可能是噪声。单调假设被证伪（峰值在中点而非高点），阈值假设未证实（样本不足）。**

## 诚实评估

### 统计显著性问题（关键）

**N=6/cell 远不够统计显著。** 从 5/6 到 6/6 的翻转（83%→100%）在二项分布下：

$$P(\text{6/6} \mid p=5/6) = (5/6)^6 \approx 0.335$$

**三分之一概率**——这不是罕见事件，完全可能是噪声。

更严格地说：
- 要达到 80% power 检测 5pp 增益（α=0.05），需要 N≈352/cell（二项检验近似）
- 检测 10pp 增益需要 N≈130/cell
- 当前 N=6，power ≈ 0（无法检测任何实际效应）

### 三个发现

**1. 单调假设被证伪（唯一可靠发现）**

增益曲线不是单调递增的：
- a=0.00 → 0% 增益
- a=0.50 → +17~33pp 增益（峰值）
- a=1.00 → 0~33pp 增益（非峰值）

**纯 evidence（a=1.00）不是最优的。** 这直接否定了"对齐度越高，增益越大"的单调假设。

可能解释：
- **混合对齐度更优**：50/50 混合可能提供了"多样性"——既有结构信号又有随机性，让 LLM 更容易从噪声中提取信号
- **纯 evidence 过度结构化**：evidence blueprint 的结构可能过于规则，LLM 难以从中提取任务相关信息
- **随机噪声增强**：少量随机性可能帮助 LLM 避免过拟合于特定结构模式

**2. 阈值假设未证实（样本不足）**

a=0.50 处的"阈值"可能是：
- 真实阈值（需要更多数据验证）
- 噪声（N=6，P≈0.335）
- 特定 blueprint 的偶然性（3 个 blueprint 可能恰好在这个对齐度表现更好）

**3. 单模型、单拓扑限制**

- 仅测试了 deepseek-v4-flash 一个模型
- 仅测试了 sequential + fan_out 两种拓扑
- 未跨模型验证——不同模型的响应模式可能不同

## 与 P1/R1 的关联

### P1（单点对比）

P1 是 R3 的特例（a=1.00 vs a=0.00）：
- P1 结果：hub +5.1pp, reachability +5.6pp（小效应，motif_family 排除后）
- R3 发现：a=1.00 处增益为 0（hub）或 +33pp（reachability）——与 P1 不一致

**可能原因**：
- P1 用 25 blueprints，R3 用 3 blueprints——样本量差异大
- P1 用全部 4 拓扑，R3 仅 2 拓扑
- P1 用 4-6 节点图（简单任务），R3 用 8-10 节点图（更难任务）
- **不同任务难度下，对齐度效应可能不同**

### R1（机制检验）

R1 证伪了三个候选机制（特征附加/任务对齐/密度相关），R³ 提供了新方向：
- **对齐度不是单调的**——峰值在中间
- 这可能解释了 R1 中"任务对齐"假说为何不成立——不是"对齐"本身有问题，而是"单调对齐"这个方向错了

## 教训（新）

1. **"阈值"不等于"真实阈值"**：N=6 的 binomial 检验 power ≈ 0。脚本报告"threshold found"是算法判定（增益>5pp），不是统计显著性。
2. **非单调性比单调性更有信息量**：P1 测单点，R3 测梯度，发现了 P1 看不到的模式（峰值在中点）。梯度设计永远优于单点对比。
3. **任务难度影响效应大小**：4-6 节点图任务太简单（基线 100%），8-10 节点才有可观测效应。
4. **"纯 evidence 最优"不是默认假设**：a=1.00 不是最优——混合对齐度可能更好。这对"结构注入策略"有直接指导意义。
