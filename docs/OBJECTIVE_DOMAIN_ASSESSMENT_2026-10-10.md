## 二、国际前沿上本项目的真实位置

**同基底（MaleCNS v1.0，2026-09-03 发布，166,700 神经元 / 124,177,617 突触 / 262 雄性专有细胞类型）在国际上的用法**：

| 工作 | 用 MaleCNS 做什么 | 结果 |
|---|---|---|
| **KAIST（arXiv:2610.10014, 2026-10-07）** | MaleCNS 作为固定循环拓扑，学每条 edge 的标量 → 求解 bounded addition + grounded relational language | Addition **92.77% vs 67.93% rewire**（+25pp）；语言 **61.59% vs 44.17%**（+17pp）；canonical interface 在 21-graph 对照中排第 1 |
| **Fly Language Model FLM**（2026-09） | MaleCNS 接到冻结 LFM2.5-1.2B 做 reservoir | 3 seeds 全部**输给 direct-input 对照**（未显示 connectome gain）；长程记忆被 0.6/token 压缩率抹掉 |
| **AdaptOrch**（arXiv:2602.16873, 2026-02） | 4 种编排拓扑在 LLM 基底上 | 拓扑差 **+12~23%**；**结构 > 模型** |
| **Fly64 / 机器人控制**（2026-10） | MaleCNS 接 Super Mario 64 视觉 → 运动命令 | 非训练型、非目标导向——**展示性** |
| **本项目** | 116 单元 / 66 连接 / 83 端口 / 25 蓝图 / 12+7+4 规则 / 23 门禁 | 结构证据库 + 拓扑度量；**GA 0/7 输随机**（ESN 储备池基底）；故障隔离 **92.6%（25/27, Δ28pp）** |

**关键观察**（诚实版）：
- KAIST 证明了 **MaleCNS 的"高阶结构"在特定人工任务上有 inductive bias**——本项目锚定同一个 v1.0 数据。
- FLM 证明了 **MaleCNS 接进 LLM 后没有 unique gain**——**这恰好解释了本项目 Phase 3 的 0/7**（本项目是在 ESN 储备池上测的，与 FLM 类似基底，密度 0.002–0.023）。
- AdaptOrch 证明了 **LLM 编排基底上拓扑可以带来 12–23% 增益**——**本项目从未在这个基底上测过自己**（这是定位文档里说的 P1 实验）。
- **本项目唯一在 KAIST / FLM / AdaptOrch 都没有的东西**：结构证据库的**类型化颗粒度**（83 typed 端口 + 66 连接类型带 sign/fanout/span/delay/plastic + 12+7+4 组合规则 + 23 门禁 + PROV 血统）+ **故障隔离度量的完整度量体系（25/27, Δ28pp）**。

## 五、无法对外发的（诚实负面清单）

**必须在报告顶端写清楚，任何对外沟通都不能越过这条线**：

1. **不能发"数字生命"论文**——4 条特征 = 0，审稿一击致命
2. **不能发"超越生物"论文**——Phase 3 已实测负，本项目明确不宣称
3. **不能对标"数字线虫"级别产出**——本项目无 302 神经元全闭环仿真，无 Super Mario 演示级产物
4. **不能说"我们做出了数字生命"**——这是话术不是实测
5. **不能宣称"计算力 / 能耗优势"**——0/7、0/24 实测为负
6. **不能说"结构 100% 有效"**——只有 37/116 = 31.9% 有真实锚定，79/116 = 68.1% 是跨物种声明（声明性不是验证性）
7. **不能说"跨物种宽度已被验证"**——宽度是声明性，v2.53.0 的 role 绑定给出了首个验证性证据（141/184 组跨 ≥2 物种），但仍是拓扑等价性而非行为等价性

## 六、战略建议：修内功 + 保密 + 可对接 + 顶尖

### 6.1 保密边界（三层）

| 层 | 内容 | 策略 |
|---|---|---|
| **L0 开源 / 公开** | 结构证据库的白皮书级摘要、门禁方法论、PROV 血统格式、故障隔离度量 | 公开发布（arXiv preprint / 综述投稿），**建立学术声誉** |
| **L1 半开放** | 完整代码 + 数据（MIT / CC-BY 混合许可）；MCP 46 工具；CLI + HTTP API | GitHub 开源，但**结构证据库内部索引私有**（防止竞品直接复制证据） |
| **L2 私有（Tier-2 IP）** | 私有 `flybrain-connectome-core` 仓（组合规则引擎、中间件、内部实现）；结构签名算法细节；PROV 血统密钥 | **保留**，不对外；这是"顶尖"的技术护城河 |

**这条线的关键**：**把"结构证据 + 拓扑度量"作为学术声誉对外发，把"实现细节 + 完整证据库"作为商业/科研护城河**。学界认可 + 内部顶尖，两条同时成立。

### 6.2 三时间窗行动（**零外部依赖优先**）

| 时间窗 | 内功（Phase A–D） | 对外（论文 + 对接） |
|---|---|---|
| **0–3 个月**（现在–2026-12） | Phase A（活体运行时 + 边界强制 + 持续监护 + 代谢计量）+ Phase D-结构判据（端口反应引擎 + 新物种登记） | 提交"结构证据库 + 门禁方法论"简版 arXiv preprint；**投稿 Nature Computational Science**；邮件联系 KAIST Daeshik Kim 团队探讨 P1 联合实验 |
| **3–6 个月**（2027-01–03） | Phase B（自愈四步循环 + 结构性验收）+ Phase C（clone/mutate/世系树 + 存活判据 + DGM 档案库） | VITAL 国际联盟筹备期申报（结构证据 / 拓扑度量子方向）；**"结构退化度量"投稿 Nature Methods / eLife**；ICLR 2027 投稿（若 P1 出结果） |

### 6.3 关于"顶尖"的定义（不讨好版）

**"顶尖"在本项目语境下的准确含义**：
- ❌ **不是**"打败马雷"（他们做的是 302 神经元全闭环仿真，本项目是结构证据库，赛道不同）
- ❌ **不是**"发一篇 Nature 主刊"（本项目当前没有能撑起 Nature 主刊的活体产物）
- ✅ **是**"**在结构证据 + 拓扑度量这个子领域做到国际第一梯队**"——这个子领域目前**几乎空白**
- ✅ **是**"**结构退化度量成为国际引用的标准**"——填补 AdaptOrch / 谷歌 / DGM 都没有的空白
- ✅ **是**"**跨物种电路等价性度量的首创者**"——本项目 v2.53.0 的 role 绑定是国际首个系统实现

**这个"顶尖"是可信的、可达成的、有事实锚定的**——比"对标数字线虫"可信得多。
