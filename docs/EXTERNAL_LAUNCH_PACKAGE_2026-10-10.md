## 四、绝不能对外讲的 5 条红线

| # | 不能说 | 为什么 |
|---|---|---|
| 1 | "**数字生命实现了**" | 我们的"生命"是**结构级**（模块+端口+边规则），不是**生物级**（神经元活动）；8 条特征有实现但都是极简版 |
| 2 | "**超越生物**" | 无对照实验支持，Phase 3 已证伪（0/7 输随机）；2026-10 谷歌自陈"非生物起源证据" |
| 3 | "**对标天宝 / 数字鼠脑**" | 我们没有活体仿真产物；马雷"天宝"是 302 神经元全闭环，我们是最简生命循环 |
| 4 | "**可验证性 = 生物学起源**" | AdaptOrch / 谷歌 2024 都证明"非生物起源"——**可验证性 ≠ 生物起源**，两者是不同问题 |
| 5 | "**4 条特征 = 生命**" | 4 条是**操作性判据**，不是**哲学定义**；把操作性判据等同生命定义会被哲学/科学哲学批评 |

## 六、3 个决策问题（等用户拍板）

**问题 1：是否结束完全封闭期？**

用户原策略："完全封闭到 Phase A-D 完成再对外"。
**现在 A-D+E3+收官实证全部完成，条件已满足**。
- ✅ 结束：v2.58.0 具备对外交付能力（论文/评选/合作对接）
- ❌ 继续封闭：等 E1/E2 完成，但**硬阻塞在 LLM 访问**

**推荐**：结束。**8 阶段闭环实证是"数字生命特征整体成立"的最强证据**，比任何单 Phase 都更能打动评审。

---

**问题 2：优先发什么？**

- **A. 3.2 结构级数字生命 8 阶段闭环**（arXiv preprint，2-3 周）——**新闻价值最高**
- B. 3.1 结构退化度量（Nature Methods，4-6 周）——学术认可度最高
- C. 3.3 结构演化闭环方法论（NeurIPS，4-6 周）
- D. 3.4 负结果科学（arXiv，1-2 周）——最快但争议风险高

**推荐**：**A 优先**（新闻价值 + 交付速度双优），B 作为同期跟进。

---

**问题 3：是否推进 E1/E2？**

- **E1 AdaptOrch 自适应拓扑**：**核心算法可零外部依赖实现**（任务 DAG → 拓扑选择的启发式搜索、结构签名评估函数、结构空间搜索），LLM 调用留 interface
- **E2 P1 LLM 编排对照**：**硬阻塞**在 LLM 访问；本项目唯一能真正结案"0/7 是结构无效还是测错基底"的实验

**推荐**：
- **E1 现在做**——是 Phase E 剩余项里唯一零外部依赖的
- **E2 等 LLM 就绪**——用户之前明确说"P1 实验延后"，尊重这个决策
