# 中期融合评估：图基础模型 · EvoAgentX · AutoScientists

**日期**：2026-10-11
**性质**：**评估文档**，非实测报告。所有结论基于公开信息 + 本项目已有实验。
**前置条件**：融合 A（Gate 30 判据辅助）与融合 B（两级调用）已在 v2.63.0 落地。

---

## 零、一句话

> 图基础模型（G-reasoner / BrainGFM）解决 L3 理论层，但**成本最高、收益不确定**；
> EvoAgentX 提供外部对照实现，**ROI 中等**；AutoScientists 自动化实验循环，
> **必须在 S6 纪律落地后才能引入**——否则只是更快地产生错误结论。

---

## 一、图基础模型（融合 C）

### 1.1 现状诊断

本项目当前的结构表示是**符号化**的：

| 层 | 表示 | 可学习 |
|---|---|---|
| 结构签名 | sha256 哈希 | ❌ |
| 结构度量 | 平均度 / 聚类系数 / 直径 | ❌ |
| motif 家族 | 离散标签（3 类） | ❌ |
| 能力分布 | 22 类计数 | ❌ |

**缺口**：没有"可学习的连续表征"。
- R1 机制检验（隔离效应量是 28pp，为什么？）—— 符号度量只能给出**是什么**，不能给出**为什么**。
- 结构邻域分析（"哪些结构是同类"）—— 符号度量只能给出**精确距离**，不能给出**语义相似**。

### 1.2 候选技术

| 技术 | 来源 | 参数规模 | 关键能力 | 落地难度 |
|---|---|---|---|---|
| **G-reasoner** | ICLR 2026 | 34M GNN + LLM | QuadGraph 四层统一图接口；异构知识源标准化 | **高**（需适配 QuadGraph 接口） |
| **BrainGFM** | ICLR 2026（arXiv:2506.02044，开源） | 未公开（推测 100M+） | 40 万脑图 / 27 数据集预训练；图对比 + 图掩码自编码 | **高**（需 GPU 训练/推理） |

### 1.3 集成路径（如果做）

```
Phase C.1: 适配层（2-3 天）
  - 把本项目 116×66×83 符号结构转为标准邻接矩阵
  - 用 BrainGFM 的预训练权重做 zero-shot embedding
  - 产出：每个 blueprint 的连续向量（d=256 或 512）

Phase C.2: 验证层（1 周）
  - 在 R1 的 P1 预测上：embedding 空间能否解释隔离效应量的额外方差
  - 对照：符号度量 R²=0.15 vs embedding R²=?
  - 证伪条件：若 embedding R² < 0.15 + 0.05 → 关闭融合 C

Phase C.3: 生产化（2 周，仅在 C.2 通过后）
  - 集成到 llm_orchestrator 的 evidence block
  - 新增 MCP 工具：structure_embedding(profile_id) → vector
```

### 1.4 成本-收益评估

| 项 | 估算 |
|---|---|
| **时间成本** | 3-4 周（含适配 + 验证 + 可能的训练） |
| **硬件成本** | BrainGFM 推理需 GPU（本机无 CUDA，需云 GPU） |
| **技术风险** | 高——BrainGFM 的预训练域（脑图）与本项目（抽象拓扑）可能分布偏移 |
| **预期收益** | 不确定——可能解释 R1 的 15% 方差，也可能不解释 |
| **与纪律的张力** | 中——表征学习容易被误读为"我们的结构更强"，必须定位为分析工具 |

### 1.5 建议

> **暂缓。** 理由：
> 1. R1 已经被证伪（P1/P2 同时失败），说明"结构×任务对齐"假说本身就不成立——
>    embedding 即使能解释方差，解释的也是错误假说的方差。
> 2. 硬件约束（无本地 GPU）使集成成本高。
> 3. **L3 理论层的突破不应依赖外部表征——应该从本项目自身的负结果里推导。**
>    0/7、0/24、GA 8/8、P1 无优势——四条负结果指向同一个结论：
>    **"结构增益不来自拓扑选择，而来自任务-结构对齐度的精确匹配。"**
>    这是理论解释，不需要 embedding。

**重新评估触发条件**：当 R2 密度扫描或 R4 敏感性边界发现符号度量**无法解释**的现象时。

## 二、EvoAgentX（类别 3 · 自进化框架）

### 2.1 现状诊断

本项目已有：
- `population.py`：DGM 式 archive（保留"有趣但非最优"的解）
- `self_evolving_loop.py`：8 阶段生命闭环
- `repair_engine.py`：三种原子补丁（add_unit / rewire / drop_unit）

**缺口**：没有**外部对照实现**。
- 本项目的自进化选择压是**结构健康**（二分），EvoAgentX 用**任务指标**。
- 两者的差异本身就是 R3 的实验条件——但需要 EvoAgentX 实际跑一遍才能对照。

### 2.2 集成路径

```
Phase E.1: 评估（1 天）
  - 读 EvoAgentX 文档，确认其 agent 接口是否支持自定义 fitness function
  - 判断：能否把本项目的 structure_health 作为 fitness 传入

Phase E.2: 适配（3-5 天，仅在 E.1 通过后）
  - 写 adapter：本项目 blueprint → EvoAgentX agent state
  - 写 adapter：structure_health → EvoAgentX fitness score
  - 跑 100 代进化，对照本项目 self_evolving_loop 的结果

Phase E.3: 对照分析（2 天）
  - 对比：本项目（结构健康选择压）vs EvoAgentX（任务指标选择压）
  - 预期差异：本项目保留更多"有趣但非最优"的解；EvoAgentX 收敛更快
  - 这是 R3 的一个外部对照点
```

### 2.3 成本-收益评估

| 项 | 估算 |
|---|---|
| **时间成本** | 1-2 周 |
| **硬件成本** | 低（纯 CPU，agent 框架） |
| **技术风险** | 中——接口适配可能困难 |
| **预期收益** | 中——提供外部对照点，但不是新能力 |
| **与纪律的张力** | 低——明确定位为"外部对照"，不宣称性能优势 |

### 2.4 建议

> **短期可做。** 理由：
> 1. 成本低（1-2 周，无硬件约束）
> 2. 提供 R3 的外部对照点（有独立价值）
> 3. 不改变任何结论，只是验证已有设计

**优先级**：低于融合 B（已完成）和融合 A（已完成），高于图基础模型。

## 三、AutoScientists（类别 5 · 科学发现 agent）

### 3.1 现状诊断

本项目已有：
- Gate 30 五要素检查（命题/预测/证伪/复算/边界）
- S6 纪律（对照组可得分性）
- 研究命题库（research_claims.json）
- 实验脚本（R1/R2/R4）

**缺口**：实验循环是**手动**的——
1. 人写假说
2. 人跑实验
3. 人分析结果
4. 人更新命题库

AutoScientists 可以自动化 **1→2→3**，但**3→4**（更新命题库）必须保持人工。

### 3.2 关键约束：S6 前置

> **AutoScientists 类自动化实验必须在 S6 纪律落地后才能引入。**

S6 已在 Gate 30 落地（v2.61.0），但**自动化实验的 S6 检查必须在生成假说时就执行**，
而不是等实验跑完再检查。否则：
- 自动化生成"motif_family 任务" → S6 检查 → 发现对照组不可得分 → 浪费算力
- 正确顺序：生成假说 → S6 预检 → 通过才跑实验

### 3.3 集成路径（如果做）

```
Phase A.1: 评估（1 天）
  - 读 AutoScientists 文档，确认其假设生成接口
  - 判断：能否在假设生成阶段注入 S6 检查

Phase A.2: S6 前置适配器（3 天）
  - 写 pre-check：新假说 → S6 对照组可得分性检查
  - 不通过 → 拒绝生成，返回"对照组不可得分"原因
  - 通过 → 进入 AutoScientists 流程

Phase A.3: 实验循环自动化（5-7 天）
  - 自动生成假说 → S6 预检 → 跑实验 → 分析 → 更新 research_claims.json
  - 人工审核节点：每 5 个假说暂停，人工 review
```

### 3.4 成本-收益评估

| 项 | 估算 |
|---|---|
| **时间成本** | 2-3 周（含 S6 适配器） |
| **硬件成本** | 中（需 LLM 调用，但融合 B 已降本 50%） |
| **技术风险** | **高**——自动化可能产生伪效应（P1 的教训） |
| **预期收益** | 中——加速实验循环，但不产生新结论 |
| **与纪律的张力** | **高**——必须严格 S6 前置，否则自动化 = 更快地犯错 |

### 3.5 建议

> **暂缓，但设计好接口。** 理由：
> 1. P1 的伪效应（motif_family 对照组 0% 得分）正是缺 S6 前置造成的
> 2. 当前 R1/R2/R4 三个实验都已跑完，短期内不需要自动化
> 3. 当假说数量 > 10 且实验周期 < 1 天时，自动化的 ROI 才为正

**重新评估触发条件**：当 research_claims.json 的命题数 > 10 且平均实验周期 < 1 天时。

## 五、诚实边界

1. **本报告是评估，不是实测。** 所有成本/收益估算基于公开信息和类比推理。
2. **EvoAgentX / AutoScientists 的文档可能已更新**——落地前须核对原始仓库。
3. **图基础模型的 GPU 需求未验证**——BrainGFM 的推理可能比预期轻量。
4. **融合 C 的"暂缓"不是"否决"**——当 R2/R4 发现符号度量无法解释的现象时，重新评估。
5. **AutoScientists 的"暂缓"是硬约束**——S6 前置未落地前，自动化实验 = 更快地犯错。
