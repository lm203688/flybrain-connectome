### R1 · 模块化结构的故障隔离：普遍性成立，但程度不可由纯结构预测

**这是数据最就绪、理论对接最明确的一条。**

| 项              | 内容                                                                                                                                                                                                               |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **命题**         | 模块化拓扑**普遍**提供故障隔离（92.6%），但隔离的**程度**由「结构 × 任务对齐度」共同决定；**纯结构只能解释其中一小部分**（R² ≈ 0.15），因为"哪个模块承载读出"这一信息**不在接线图中**                                                                                                     |
| **已有数据**       | 27 拓扑全量实测：25/27 表现 H1 模块化；效应量中位 Δ28 pp；9 个结构特征的相关系数（模块度 Q = **-0.335**，谱半径 0.277，密度 0.254，k 0.131）；in-sample R² = 0.15；**1 对结构不可分辨但判定相反的对照**                                                                     |
| **机制假说**       | 隔离 = f(结构隔离性, 任务-模块对齐)。结构提供"**隔离的可能性**"，任务对齐决定"**隔离是否被兑现**"。二者是**乘积关系**而非加性关系                                                                                                                                    |
| **可证伪预测**      | **P1**：加入"模块→读出结构可达性"作为第 10 个特征后，R² 显著上升（若仍 ≈ 0.15 → 假说错）<br />**P2**：在**固定拓扑**下仅改变读出模块，隔离效应量应发生显著变化（若不变 → "任务对齐"不起作用）<br />**P3**：隔离效应量与"跨模块边密度"负相关（若为正 → 机制错）                                                  |
| **证伪条件（预先声明）** | 若 P1 与 P2 **同时**不成立 → **"结构 × 任务对齐"假说被证伪**，应关闭该方向并发布负结果                                                                                                                                                          |
| **学术对接**       | **Friston 2008「modularity of brain」争议**（模块化是否带来功能优势，至今未定论）；已有 double dissociation 证据（Geddes 2014 / Glenberg 2014 / Campanella 2022 / Vaidya PNAS 2010）但**未量化**；本项目给出**首个量化对照（92.6%）**，并进一步给出**可预测性的边界（R²=0.15）** |
| **发表路径**       | 网络神经科学 / 复杂系统：**Network Neuroscience · PLOS Computational Biology · Phys Rev E · Chaos**；会议：**ALIFE · NetSci · CogSci**                                                                                          |
| **外部依赖**       | **无**（数据已有，仅需扩样）                                                                                                                                                                                                 |
| **扩样需求**       | 27 → **N ≥ 100** 拓扑（可合成生成），以获得 held-out 验证（现有 27 只能做 in-sample，这是当前最大方法学弱点）                                                                                                                                      |

> **这条命题的独特价值**：它**同时包含一个正面结论和一个负面结论**——  
> "模块化普遍带来隔离"（正面，推翻"未定论"）+ "但程度不可由结构预测"（负面，划定边界）。  
> **正负兼备的结论比单纯的正面结论更可信，也更容易被引用。**

### R2 · 结构搜索的可搜索性条件：为什么 GA 输给随机

| 项         | 内容                                                                                                                                                      |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **命题**    | 在稀疏结构空间（密度 0.002–0.023）中，适应度景观**不存在可搜索的梯度**，因此任何基于适应度的搜索（GA）**系统性劣于随机采样**；存在一个**密度阈值 d***，超过它之后适应度搜索才开始有效                                               |
| **已有数据**  | GA vs 随机：**8/8 seeds GA 输**（+29% 适应度）；锁定架构时 GA 收敛 57 边 vs 随机 50 边；放开约束时 GA 收敛 9–11 边（-84% 线成本）vs 随机 18–43 边                                             |
| **机制假说**  | 稀疏空间中，结构变异对功能的影响**几乎无区分度**（大多数变异落在"能力悬崖外"），导致景观**平坦或纯噪声**；密度上升后，变异才开始"被功能感知"                                                                            |
| **可证伪预测** | **P1**：GA/随机 的性能比随密度**单调上升**，并在某 d* 处穿越 1.0<br />**P2**：景观粗糙度（自相关长度 / 局部最优数）随密度下降<br />**证伪条件**：若 GA 在**所有**密度下都不优于随机 → "密度决定可搜索性"不成立，应改为"此适应度定义本身无信息量" |
| **学术对接**  | **Kauffman NK 模型**（景观粗糙度 vs 可搜索性）；进化计算中的"无免费午餐"与"景观分析"传统；**结构化搜索空间的可搜索性理论**                                                                             |
| **发表路径**  | **GECCO · IEEE TEC · ALIFE · Artificial Life 期刊**                                                                                                       |
| **外部依赖**  | **无**                                                                                                                                                   |
| **附加价值**  | 这条结论有**方法论外溢**：它给出"什么时候该用 GA、什么时候不该用"的判据，对**所有**在稀疏结构空间做优化的领域都适用                                                                                        |

### R3 · 结构价值 × 基底对齐度：统一解释四个独立观察（**最有前沿性**）

**这条最有影响力，也最需要外部条件。**

| 项               | 内容                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **命题**          | **同一结构的价值不是结构的固有属性，而是「结构-任务对齐度」的函数。** 对齐度低于阈值时结构增益趋于 0（甚至为负）；高于阈值时增益显著。这统一解释了四个相互冲突的独立观察                                                                                                                                                                                                                                                                                                                                      |
| **四个观察（全部已核实）** | ① **本项目 0/7**：生物 motif 不优于随机（**ESN 稀疏储备池**基底，密度 0.002–0.023）<br />② **FLM 2026-09**：同一 MaleCNS 接冻结 LLM 做 reservoir，**3 seeds 全输 direct-input**（同基底类型）<br />③ **KAIST arXiv:2610.10014 2026-10-07**：**同一 MaleCNS** 作固定循环拓扑，学 edge 标量 → addition **92.77% vs 67.93% rewire（+25 pp）**、语言 **+17 pp**（**结构被当作 inductive bias，与任务图结构对齐**）<br />④ **AdaptOrch arXiv:2602.16873 2026-02**：LLM 编排基底上仅改拓扑 **+12~23%**（**拓扑直接映射任务 DAG**） |
| **机制假说**        | 结构的价值通过"**为任务提供先验约束**"实现。当基底是通用动力学（ESN/LLM reservoir）时，结构只是**被冲掉的初始条件**；当结构直接参与任务分解（KAIST / AdaptOrch）时，它是**被兑现的先验**                                                                                                                                                                                                                                                                                                          |
| **可证伪预测**       | **P1**：构造对齐度递增的任务族，结构增益随对齐度单调上升<br />**P2**：存在对齐度阈值 a*，低于它时"本项目结构 vs 随机结构"无显著差异<br />**证伪条件**：若在高对齐任务上本项目结构**仍不优于随机** → 假说错（但 KAIST 已给出反例，故概率低）                                                                                                                                                                                                                                                                               |
| **学术对接**        | 2026 最热问题之一：**"结构什么时候重要？"**；拓扑感知 MAS（arXiv 2505.22467 立场论文）；reservoir computing 的 inductive bias 讨论                                                                                                                                                                                                                                                                                                                           |
| **发表路径**        | **NeurIPS / ICLR / ICML**（影响力最大）；或 **TMLR**                                                                                                                                                                                                                                                                                                                                                                                   |
| **外部依赖**        | ⚠️ **需要 LLM 访问**（做编排实验）——这是唯一的新外部依赖                                                                                                                                                                                                                                                                                                                                                                                           |
| **为什么最有前沿性**    | 它**不是"我们也做了一个结构"，而是"我们解释了为什么大家的结论互相矛盾"**。后者是**被引用的位置**，前者不是                                                                                                                                                                                                                                                                                                                                                                   |

## 三、硬科技壁垒的四层建立路径

**注意：这是技术壁垒，不是商业壁垒。**

| 层             | 壁垒内容                           | 现状                | 建立方式                                                                |
| ------------- | ------------------------------ | ----------------- | ------------------------------------------------------------------- |
| **第一层：数据壁垒**  | 3 连接组 + **类型化处理形式**（116×66×83） | ✅ 已有              | ⚠️ **数据本身不是壁垒（全开源）**；**处理形式才是**。应把"如何把连接组转化为 typed 可组合结构"写成方法论      |
| **第二层：度量壁垒**  | 故障隔离度量体系（效应量 + 拓扑体检 + 结构签名）    | ✅ 已有，**国际空白**     | **把度量写成规范**（定义、测量方法、误差、边界），使其可被独立复现——**可复现的度量才是壁垒**                 |
| **第三层：理论壁垒**  | R1 / R2 / R3 三条命题              | ❌ 空白              | **这是最硬的一层**：理论一旦成立且被引用，就成为该方向的**基准**。别人要么用你的理论，要么反驳你——**两种都提升你的位置** |
| **第四层：方法论壁垒** | 科研自验证纪律（可证伪预测 + 预先声明 + 负结果登记）  | 🟡 部分（项目已在做，未制度化） | **把它写成纪律并公开**——在一个"钱跑在科学前面"的领域，**方法论信誉是最稀缺的壁垒**                     |

> **核心判断**：本项目的前两层壁垒（数据 / 度量）**已经建成但不可防御**（数据开源、度量可被抄）。  
> **第三、四层才是真正不可绕过的**——理论和方法论**不能靠抄得到**。

## 四、科研自验证机制（本方案的核心创新）

### 4.1 现状：项目有"代码自验证"，缺"科学自验证"

| 类型        | 内容            | 现状               |
| --------- | ------------- | ---------------- |
| **代码自验证** | 29 门禁，每条做缺陷注入 | ✅ **已到国际同级罕有水平** |
| **科学自验证** | 理论主张的自我检验纪律   | ❌ **未制度化**       |

### 4.2 科学自验证的五条纪律（建议制度化）

| #      | 纪律            | 具体做法                                        | 已有先例                                        |
| ------ | ------------- | ------------------------------------------- | ------------------------------------------- |
| **S1** | **先写预测，再跑实验** | 任何理论主张必须先写下**可证伪的定量预测**，再运行实验。预测与结果**同时**存档 | `isolation_predictor` 的"加第 10 特征重跑"         |
| **S2** | **预先声明关闭条件**  | 实验开始前声明："若结果为 X，则关闭该方向并发布负结果"               | `NegativeResultGuard`（已实现于 `population.py`） |
| **S3** | **独立复算**      | 每个结论附带**一条命令**即可复算；样本量、随机种子、环境全部声明          | 29 门禁 + 同 seed 签名一致                         |
| **S4** | **对抗性测试**     | 主动构造**最可能推翻自己**的案例（而非只找支持证据）                | 27 拓扑中的 2 个例外样本被保留而非剔除                      |
| **S5** | **负结果登记**     | 负结果不隐藏、不淡化，进入公开登记表                          | 已有 4 条（0/7、0/24、GA 8/8、隔离不可预测 R²=0.15）      |

### 4.3 建议新增 **Gate 30 · 科研自验证门禁**

**做什么**：检查每一个**对外声明的理论主张**是否具备五要素：

```
① 命题陈述（可证伪的形式）
② 定量预测
③ 证伪条件
④ 复算命令（一条即可运行）
⑤ 样本量 + 随机种子 + 边界声明
```

**缺任一项即报红。**

**为什么这条门禁本身有价值**：

- 它把"科研诚实"从**个人品德**变成**可执行检查**
- 它是 §三 第四层壁垒（方法论壁垒）的**落地形式**
- **它是一条可以写进论文的方法论贡献**（"我们用一个门禁强制了科研自验证"）

## 八、诚实边界

1. **R1 的当前证据是 in-sample 拟合（n=27）**——`isolation_predictor_results.json` 的 caveat 已明确写"held-out set requires more topologies"。  
   **扩样到 N≥100 是 R1 成立的前提，不是可选项。**
2. **R1 的机制假说可能被证伪**，且项目**已预先声明关闭条件**。若被证伪，应发布负结果，不得改判。
3. **R3 尚未做任何实验**。四个观察（0/7 / FLM / KAIST / AdaptOrch）都是**别人的或本项目在别的基底上的**结果，  
   把它们统一起来是一个**假说**，不是结论。
4. **0/7、0/24、GA 8/8 依然是有效结论**；本方案**不翻案**，只是把它们**升级为待解释的现象**。
5. **R6 证据弱**：68.1% 单元宽度是声明性的。
6. **8 阶段闭环是"结构级"**，不是生物级；不主张意识。
7. **R3 需要 LLM 访问**——这是唯一外部依赖，也是阶段 III 的硬门槛。
8. **本方案的六条命题全部是"待验"**。写下它们不等于它们成立。  
   **本方案的价值在于"把现象变成可证伪的命题"，不在于宣布结论。**
9. **单人维护**是结构性风险：29 门禁 + 65,564 行 + 6 条研究线的维护负担需要正视。

## 十、如果只做一件事

> **做 I-1 + I-2：把 R1 从"现象"做成"带边界的规律"。**
>
> 理由三条：
>
> 1. **数据最就绪**（已有 27 拓扑全量实测 + 9 个结构特征 + 相关系数 + 1 对反例），零外部依赖；
> 2. **理论对接最明确**——直接对上 **Friston 2008「modularity of brain」至今未定论的争议**，  
>    而且本项目的结论**正负兼备**（92.6% 普遍成立 + R²=0.15 划定边界），比单纯正面结论更可信、更易被引用；
> 3. **它是唯一一条"别人做了但没做对"的题目**——  
>    生物学界有 double dissociation 证据但**从未量化**，本项目已有**首个量化对照**，  
>    **只差把 in-sample 升级为 held-out，并把机制假说检验一次。**
>
> **做完 I-1 + I-2，项目就从"有一个国际空白的数字"变成"有一条被检验过的规律"——  
> 这是"硬科技深度"的真正分水岭。**
