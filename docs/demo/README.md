# flybrain-connectome — Interactive Demo

This directory hosts a static, interactive demo of flybrain-connectome's core
capability: generating an auditable agent topology from a real connectome
blueprint.

## Quick Links

- **[Live Demo](./index.html)** — Interactive D3 visualization (5 modules × 8 agents)
- **[Topology JSON](./topology.json)** — Full topology with provenance
- **[Raw HTML](./topology.html)** — Standalone visualization (no iframe)

## Enabling GitHub Pages (one-time setup)

To publish this demo at `https://lm203688.github.io/flybrain-connectome/`:

1. Go to your GitHub repository settings
2. Navigate to **Pages** → **Build and deployment**
3. Set **Source** to "Deploy from a branch"
4. Set **Branch** to `main` and **Folder** to `/docs`
5. Click **Save**

GitHub Pages will deploy within 2-5 minutes. The demo will be live at:
`https://<username>.github.io/flybrain-connectome/demo/`

## Regenerating the demo

The demo content is generated by:

```bash
flybrain demo --no-open --blueprint predictive_coding_v2 \
  --modules 5 --agents-per-module 8
```

To update the demo with a different blueprint or configuration:

```bash
# Generate new topology
flybrain demo --no-open --blueprint <blueprint> \
  --modules <N> --agents-per-module <M>

# Copy outputs to docs/demo/
cp flybrain-connectome-mcp/generated_organisms/<name>.json docs/demo/topology.json
cp flybrain-connectome-mcp/generated_organisms/<name>.html docs/demo/topology.html
```

Then update the stats in `index.html` to reflect the new topology.

## Demo characteristics

- **Fully offline** — no CDN dependencies, no external scripts
- **Interactive** — drag nodes, hover for tooltips, click for details
- **D3.js** — force-directed graph layout
- **Dark theme** — matches the project's CLI output style
- **Single file** — `topology.html` is self-contained (all CSS/JS inline)
