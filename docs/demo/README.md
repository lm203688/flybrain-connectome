# flybrain-connectome — Interactive Demo

This directory hosts a static, self-contained interactive demo of flybrain-connectome's
core capability: generating an auditable agent topology from a real connectome
blueprint (MaleCNS v1.0 derived motifs).

## Live demo

Once GitHub Pages is enabled (see below), the demo is available at:

```
https://lm203688.github.io/flybrain-connectome/demo/
```

## Enabling GitHub Pages (one-time setup — 5 minutes)

Follow these steps **in order** in your GitHub account (log in as `lm203688`):

### 1. Open the repo's Pages settings

Go to: **https://github.com/lm203688/flybrain-connectome/settings/pages**

You should land on the "GitHub Pages" settings page.

### 2. Set Source

- Under **Build and deployment** → **Source**
- Select **"Deploy from a branch"**
- (Do NOT pick "Use GitHub Actions" unless you want to add a workflow later)

### 3. Set Branch and Folder

- **Branch**: `main`
- **Folder**: `/docs`

### 4. Click Save

The page will show "There isn't a GitHub Pages site here" for 2–5 minutes
while GitHub builds and deploys.

### 5. Verify

Once ready, visit:

```
https://lm203688.github.io/flybrain-connectome/demo/
```

You should see the interactive D3 topology visualization.

### Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| "There isn't a GitHub Pages site here" after 10 min | Build in progress | Check **Actions** tab for the `pages-build-deployment` workflow status |
| 404 at `/demo/` | Folder set to `/` instead of `/docs` | Go back to Pages settings, set Folder to `/docs` |
| Blank page | Missing `.nojekyll` | Already in the repo — verify by refreshing |
| Broken layout | Browser cache | Hard-refresh (Ctrl+F5) |

## Files in this directory

| File | Purpose |
|---|---|
| `index.html` | Landing page with iframe-embedded demo, stats, quickstart |
| `topology.html` | Standalone interactive D3 visualization (46 nodes, 25 edges, drag + hover) |

| `.nojekyll` | Empty file — tells GitHub Pages to skip Jekyll processing |
| `README.md` | This file |

## Regenerating the demo

The demo content is generated by:

```bash
python flybrain_cli.py demo --no-open --blueprint predictive_coding_v2 \
  --modules 5 --agents-per-module 8

# Copy outputs to docs/demo/
cp flybrain-connectome-mcp/generated_organisms/demo_predictive_coding_v2_m5_a8.json docs/demo/topology.json
# Then regenerate topology.html via _build_demo.py (see git history)
```

## Demo characteristics

- **Fully offline** — no CDN dependencies, no external scripts, no API calls
- **Interactive** — drag nodes, hover for tooltips, click for details
- **Dark theme** — matches the CLI output style
- **Self-contained** — `topology.html` is a single file (18 KB, all CSS/JS inline)
