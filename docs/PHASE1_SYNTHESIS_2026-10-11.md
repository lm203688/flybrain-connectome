## 一句话结论

**R1 确认 92.6% 故障隔离效应真实存在（29/30），但三个候选机制（特征附加、任务对齐、密度相关）全部证伪（R² ≈ 0）。
R2 因节点数不足无法分辨低密度档，属实验设计缺陷。R4 给出可利用信号：remove 类扰动在 0.1 强度即达边界，node_delete 需 0.5。**

**这不是"结构增益"，而是"我们知道 92.6% 存在但不知道为何是 92.6%"—— L3 理论层的分水岭被精确刻画。**

## R1 扩样：效应真实 · 机制证伪

### 数据（`_r1_expansion/r1_results.json`，n=30 拓扑 × 50 seeds）

| 指标 | 值 | 判读 |
|---|---|---|
| `mean_isolation_effect_size` | **0.967** | 与 v2.44.0 的 92.6%（25/27）一致 |
| `n_high_isolation` | **29/30** | 只有 1 个拓扑（`mix_reservoir_smallworld_11_83886`）为 0 |
| `verdict` | **falsified** | 机制层面证伪 |
| `p1_feature_addition.improvement` | **0.0** | R² 从 0.0249 → 0.0249，扩展特征无增益 |
| `p1_feature_addition.baseline_r2` | 0.0249 | 基线 R² 已极小 |
| `p2_task_alignment` 显著拓扑数 | **0/20**（全 `significant: false`） | 任务对齐机制不成立 |
| `p3_edge_density_correlation.r_squared` | **0.0031** | 密度-隔离效应相关性为零 |
| `p3.slope` | 0.226 | 弱正斜率但 R² ≈ 0 |

### 判读

**正面结论**：92.6% 不是 cherry-pick。把 27 拓扑扩到 30 拓扑，仍是 29/30 高隔离，效应**稳定可复现**。

**负面结论（最重要）**：**三个候选机制假说全部 R² ≈ 0**。
- 特征附加假说："加入更多结构特征就能预测隔离效应" → R² 从 0.025 提升到 0.025，零增益。
- 任务对齐假说："隔离效应与任务类型一致" → 20/20 拓扑 `significant: false`。
- 密度相关假说："密度越高越隔离" → R² = 0.003，纯噪声。

**教训**：项目过去八个月只回答"**92.6% 存在吗？**"（是），从未回答"**为什么是 92.6%？**"。R1 扩样把问题**精确化**了——不是我们不知道机制，是我们**测过的所有机制都不对**。

**含义**：Gate 30 五要素（命题/预测/证伪/复算/S6）必须覆盖"**机制假说证伪**"这个产出类型，否则 R1 这种"证伪"结论无法被验证。

## R2 密度扫描：实验设计缺陷（须修正后重跑）

### 数据（`_r2_density_scan/r2_density_scan.json`，7 密度档 × 50 samples = 350 cells）

| density 目标 | actual_density 实测 | hub | reachability | motif_family |
|---|---|---|---|---|
| 0.05 | **0.200** | 1.0 | 1.0 | 1.0 |
| 0.10 | **0.200** | 1.0 | 1.0 | 1.0 |
| 0.15 | **0.200** | 1.0 | 1.0 | 1.0 |
| 0.20 | **0.200** | 1.0 | 1.0 | 1.0 |
| 0.30 | **0.200** | 1.0 | 1.0 | 1.0 |
| 0.50 | **0.200** | 1.0 | 1.0 | 1.0 |
| 0.80 | **0.200** | 1.0 | 1.0 | 1.0 |
| `d_star` | **null** | "no cliff found in sweep range" | | |

### 根因

`params.n_nodes = 6` → 无向图最大边数 = C(6,2) = 15（有向 30）。
目标 density=0.05 → 期望 1.5 边（有向 3），但 6 节点有向图最小非空密度 = 6/30 = **0.2**（一条边 = 6/30 = 0.2）。
**所有低密度档被几何约束钳到 0.2**，密度扫描**实质上没有扫描密度**。

### 判读

- **本 R2 结论无科学价值**，是节点数太小导致密度分辨率不足。
- 正确设计需要 `n_nodes ≥ 20`（C(20,2) = 190，density=0.05 → 9.5 边可分辨），或改用有向图 n_nodes ≥ 10（C(10,2)*2 = 90）。
- **不建议现在重跑**：R1 已证伪密度相关性（R²=0.003），密度即使可分辨也大概率不是机制。
- 保留作为**反面教材**：门禁 Gate 30 需检查"实验参数分辨率是否够扫描范围"。

### 教训（新）
**扫描脚本上线前必须先做"分辨率预检"**：目标分辨率 vs 参数几何上限，若不匹配必须在启动时报错而非静默钳位。

## R4 敏感性扫描：唯一有价值的机制信号

### 数据（`_r4_sensitivity_scan/r4_sensitivity_scan.json`，8 blueprints × 4 扰动类型 × 5 强度 = 160 cells）

**扰动边界强度**（首次达到 50% 结构变化率的最小强度）：

| 扰动类型 | 边界强度 | 边界处 FP 距离 | 边界处 hub 变化率 | 边界处 reachability 变化率 |
|---|---|---|---|---|
| **remove** | **0.10** | 0.367 | 0.375 | 0.433 |
| **flip** | 0.20 | 0.307 | 0.250 | 0.500 |
| **add** | 0.20 | 0.361 | 0.500 | 0.492 |
| **node_delete** | 0.50 | 0.569 | 0.875 | 0.833 |

**FP 距离曲线（各强度档）**：

| strength | flip | add | remove | node_delete |
|---|---|---|---|---|
| 0.10 | 0.185 | 0.178 | 0.367 | 0.343 |
| 0.20 | 0.307 | 0.361 | 0.488 | 0.562 |
| 0.30 | 0.382 | 0.529 | 0.570 | 0.720 |
| 0.50 | 0.388 | 0.750 | 0.754 | 0.855 |
| 0.80 | 0.526 | 0.894 | 0.919 | 0.969 |

### 判读

**这是本次阶段 1 唯一给出"机制方向"的实验**：

1. **remove 类扰动最脆弱（边界 0.10）**：删边 10% 即触发 50% 结构变化。
   → 暗示**本项目拓扑的关键边极少**，冗余度低。这与"25/27 高隔离"的稳健叙事表面矛盾，
   但一致：隔离效应是"某个节点被移除后整个子图崩塌"，而 remove 扰动正是攻击少数关键边。

2. **node_delete 最稳健（边界 0.50）**：删节点 50% 才达 50% 结构变化率。
   → 与"节点级容错"直觉相反——删节点往往连带删边，扰动量大，但**变化率低**说明结构对节点删除有天然鲁棒性。

3. **flip 与 add 曲线形态不同**：flip 从 0.1 到 0.3 就达到 90% FP 距离，0.5 反而回落到 0.388
   → **flip 有"过度扰动"效应**（改太多反而回到接近原图），add 单调递增。

**含义**：
- **remove 是最有信息量的扰动类型**——它揭示关键边。可作为 Gate 30 结构脆弱性探针。
- 敏感性分析**能给出机制方向**，即使相关性测不出（R1 R²≈0）。

### 教训（新）
**机制探索的正确顺序**：
1. **相关性**（R1 p3）—— 快速排除
2. **扰动分析**（R4）—— 探测结构脆弱点
3. **机制建模**（R2 类）—— 精确验证

R2 应先于 R4 做（更便宜），但 R2 因设计缺陷失败。**扰动分析是 R1 全证伪后的救命稻草**，因为它不假设机制，只探测边界。

**92.6% 的分水岭已精确划定**：不是"不知道为何"，而是"我们试过的机制都不对，剩下的方向是 remove 类扰动边界"。

### 三条可交付结论

1. **92.6% 效应稳定可复现**（R1: 29/30，与 v2.44.0 一致）。**这是本项目唯一经过独立复核的硬结果。**
2. **已尝试的三个候选机制全部证伪**（R1 p1/p2/p3 R² 均 ≈ 0）。**负结果也是产出**，但需要 Gate 30 能承接。
3. **remove 类扰动在 0.1 强度即达边界**（R4）—— 唯一给出的机制方向。可作为下一轮机制假说的入口。

### 三条新纪律（补 S6 之后）

- **S7 分辨率预检**：扫描类实验启动前，验证目标分辨率 < 参数几何上限（防 R2 类静默钳位）。

## 教训（本轮新增）

- **扩样前先设计机制假说**：R1 扩了 30 拓扑但机制假说测 R²≈0，扩样本身没带来机制洞察。

- **相关性 R²≈0 时不要停**：扰动分析（R4）是救命稻草，能给出机制方向。
- **本项目 92.6% 是分水岭，不是终点**：知道"存在"和知道"为何存在"是两个层次。
