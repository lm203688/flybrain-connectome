## 2. 题目与摘要（300 字内）

**建议题目**：`[虚拟生物形态生成器：基于真实果蝇连接组的功能单元模块组合]`

**摘要骨架**（三段式）：
1. **背景与问题**：连接组数据只记录布线，不含动力学/感觉/运动假设——"哪一连接组 build 决定模型能做什么"（flybench F2，背景参考）。
2. **方法**：以 MaleCNS v1.0（167,565 神经元/124,177,617 突触，CC-BY）为真实锚定，构建 116 功能单元模块库（37 个真实锚定，31.9%），通过组合引擎（12 规则+7 嵌套+4 乘数语义）生成硅基虚拟生物形态。
3. **结果**：最小验证（组合 sensory→motor 产生 3 个跨域闭环能力对，单体 baseline 0）证明"模块组合→功能放大"机制成立；结构精简 −84% 线成本（Phase 3 实测）。

**诚实标注**：摘要中"功能放大"仅为**最小示例验证**，不得写为"全部组合空间已验证"。

## 3. 方法与实现（核心）

### 3.1 数据
- MaleCNS v1.0（CC-BY，211,604 文件/37.4GB，DATA_MANIFEST.json 全量 sha256 校验）。
- 锚定：malecns_anchors.json（58 profile/107,558 细胞/5,413 类型；sha256 `6d3a2325...`，与 functional_units.json `embodiment_source.sha256` 一致）。

### 3.2 模块库
- 116 功能单元（schema 1.0），83 端口类型，66 连接类型（schema 1.1），66 成本轴。
- 锚定分布：37/116 真实锚定（31.9%）；40 motif 仅 3 真实果蝇（7.5%）；其余跨物种文献概念模式。

### 3.3 组合引擎
- 12 组合规则 + 7 嵌套规则 + 4 乘数语义 + 27 数据驱动候选；TOTAL_TOOLS=45。
- `combination_reaction.py`："新能力判据 = 结构判据（布线），非功能判据（动力学）"。

### 3.4 生成器
- C1 生成器（`synthetic_bio_topology.py`）：motif→agent 图 + config + PROV；design_organism/evolve_organism/render_html/save_organism；离线免 key。

### 3.5 验证
- P0-1 最小验证：`capability_quantification.py`，组合后 functional_capacity=3，跨域对=3（sensory.visual→motor.escape/leg/wing）。
- Phase 3 结构精简：GA −84% 线成本。
- Phase 3.5 故障隔离：**合成拓扑** 25/27（92.6%），**非真实果蝇连接组性质**。

**诚实标注**：3.5 的 92.6% 是**合成拓扑性质**，真实连接组未直接测——申报材料必须用脚注/括号说明，不得写成"真实果蝇连接组故障隔离 92.6%"。

## 4. 结果与讨论

| 指标 | 值 | 标注 |
|---|---|---|
| 跨域闭环能力对 | 3（sensory.visual→motor.escape/leg/wing） | ✅ 最小验证 |
| 结构精简 | −84% 线成本 | ✅ Phase 3 实测 |
| 故障隔离 | 92.6%（25/27） | ⚠️ 合成拓扑性质，生物学未证实 |
| 计算力/能耗 | 0/7 优于随机 | ❌ 不宣称 |

**讨论要点**：
1. **诚实边界**：合成拓扑 vs 真实数据必须区分；功能放大未全面验证。
2. **可追溯性**：motif provenance 每单元溯源到文献/数据源。
3. **局限**：116 单元组合空间未全面验证；connectome→control policy 未实现（设计目标）。
