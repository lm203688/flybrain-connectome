## 3. 四要素评估

### 3.1 价值

- **学术信用**：官方基线 EEGNet=32.6% 低于 chance 33.3%——即使投入，名次价值极低（前三 $2,000 需远超 baselines 的表现，跨人迁移极难）。
- **能力提升**：**无**——BCI 解码是"EEG 时间序列→类别"信号分类维度，与项目"连接组结构生成/拓扑验证"**不同维度**；参赛不提升项目核心能力，反而分散精力。
- **数据/模型产出**：无（若构建则产出为独立 BCI 技术栈，非项目核心资产）。

**判定：价值低。**

### 3.2 成本

- 从零构建 BCI/EEG 全套（数据+模型+训练+提交+复现审计）：乐观 8-13 天（2026-11-06 Track2 评估），若提前 1 年准备可分摊，但**仍是独立赛道**。
- 环境改造：Python 降版本 + mne/neuralbench/moabb/braindecode 安装 + GPU（无则 CPU 慢训）——独立技术栈，与项目零 GPU 路线冲突。
- 精力分散：MICCAI 2026 连接组赛道是项目**最契合**方向（已有 F2+MICCAI baseline `77b5f6b`），BCI 准备会分散该方向投入。

**判定：成本高。**

### 3.3 风险

- **结果风险**：官方基线 EEGNet 32.6% < chance 33.3%，从零构建大概率 ≤ chance；跨人迁移极难（BCI 领域公认难题）。
- **机会成本**：投入 BCI 准备 = 减少 MICCAI 连接组赛道投入（项目核心方向）。
- **声誉风险**：若强行提交只能 Constant floor（33.3% chance）或随机模型，无学术价值，占用提交次数。

**判定：风险高。**

### 3.4 定位契合

- BCI 解码（EEG 时间序列分类）vs 项目定位（连接组结构生成/拓扑验证）——**不同维度**。
- 项目核心资产（MaleCNS v1.0 连接组/116 功能单元/组合引擎/C1 生成器）**不直接服务 EEG 解码**。
- 唯一弱关联：神经信号处理概念类比（如 spike 检测），但**不构成共享机制**——项目无 EEG/BCI 信号管线。

**判定：定位契合低。**

---

## 4. 结论

**不纳入（下轮 2027 也不值得提前准备）。**

理由：
1. 项目**无 BCI/EEG 资产**，从零构建是独立赛道，不提升项目核心能力（虚拟生物形态生成器）。
2. 官方基线 EEGNet=32.6% **低于 chance 33.3%**——即使专业模型也难过 chance，从零构建大概率 ≤ chance，无名次价值。
3. 环境阻塞（Python 3.14 无 wheel、torch CPU-only、mne/neuralbench/moabb/braindecode 未装）——独立技术栈，与项目零 GPU 路线冲突。
4. **定位不契合（根本原因）**——BCI 解码是"信号分类"维度，项目是"结构生成/拓扑验证"，核心资产不服务 EEG 解码。
5. 资金障碍已降级（万里汇+W-8BEN 可行），但**资金从来不是主障碍**——主障碍是无资产/基线低/环境/定位不契合；资金解决不改变结论。
6. MICCAI 2026 连接组赛道才是项目最契合方向（已有 F2+MICCAI baseline `77b5f6b`），聚焦不分散。

**诚实边界**：
- 不虚报参赛能力；"已注册（flybrain2026）"≠"能参赛"，注册不强制提交。
- 2026-11-06"不建议参赛"决策**仍有效**（本评估不改变该决策）。
- 下轮 2027 即使提前 1 年准备，也需先解决"无资产/基线低/环境/定位不契合"四大障碍，其中**定位不契合是根本性**——BCI 解码不是项目核心方向。
