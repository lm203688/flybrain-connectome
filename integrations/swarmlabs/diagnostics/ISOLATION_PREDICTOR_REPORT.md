# 结构能否预测故障隔离？—— 负结果报告

- 日期：2026-10-08
- 脚本：`integrations/swarmlabs/diagnostics/isolation_predictor.py`（全量 23 s / `--quick` 8 拓扑）
- 数据：`isolation_predictor_results.json`
- 前置：`FAULT_ISOLATION_REPORT.md`（27 拓扑 × H1/H2/H3 判定）

---

## 一、要回答的问题

项目已测得：**25/27 拓扑具备模块级故障隔离**（关停一个完整模块的降幅 < 随机关停等量节点的降幅）。
这 27 个数字此前只以散文形式存在于报告里。没人问过下一步：

> **能否只看接线图就预测出隔离结论，完全不跑 ESN？**

如果能，那么"结构稳定性"就从**事后测量**升级为**设计期属性**——这正是拓扑感知主线的目标，
也是通往"超快结构判断"的桥。

---

## 二、方法

对 27 个拓扑（用 `fault_isolation_experiment.py` 完全相同的加载与密化流程）：

| | 定义 |
|---|---|
| **真值** | `diff = 模块关停降幅 − 随机关停降幅`（F1 判据，`< −0.05` 判 H1） |
| **特征** | `topology_profile.py` 的结构剖面 + 补充量（k / N / 密度 / 模块度 Q / 谱半径 ρ / 模块内-间边比 / 平均模块内密度 / 关停比例 / 模块大小变异） |

然后：逐特征算与 `diff` 的皮尔逊相关；对每个特征做**单阈值扫描**（H1 vs 非 H1）；
检查是否存在"结构几乎相同、判定相反"的拓扑对。

---

## 三、结果

### 3.1 结构特征与隔离强度的相关性很弱

| 特征 | r（全量 27） | r（`--quick` 前 8） |
|---|---|---|
| modularity_q | **−0.335** | −0.396 |
| spectral_radius | +0.277 | −0.584 |
| density | +0.254 | −0.072 |
| mean_intra_density | +0.182 | −0.709 |
| **intra_inter_ratio** | **+0.152** | **−0.804** |
| k / n / med_size_over_n | ≤ 0.152 | — |
| module_size_cv | 0.000 | — |

**方法学教训（重要）**：`--quick` 前 8 个拓扑**全是 H1**（无类别差异），
`intra_inter_ratio` 在那个子集上给出 **r = −0.80** 的"强相关"；
加进 H2/H3 两个反例后塌到 **+0.152**。
**没有类别多样性的子集会产生虚假强相关**——这与项目 CLAIMS_LEDGER 里 9 次样本偏差撤回同源。

### 3.2 单阈值规则只比"永远预测 H1"多对 1 例

| 特征 | 最佳规则 | 正确数 |
|---|---|---|
| k | H1 iff k < 9 | 26/27 |
| density | H1 iff d > 0.0509 | 26/27 |
| modularity_q | H1 iff Q > 0.4931 | 26/27 |
| spectral_radius | H1 iff ρ > 0.8027 | 26/27 |
| mean_intra_density | H1 iff x > 0.3065 | 26/27 |
| med_size_over_n | H1 iff x > 0.1169 | 26/27 |
| **基线（永远预测 H1）** | — | **25/27** |

**六个不同的结构特征给出完全相同的 26/27**——这不是六个独立证据，
而是**同一个错例被六种方式各错过一次**。

### 3.3 决定性事实：结构不可分辨，判定却相反

```
evolved_target200 (H3 无结构)  k=2  d=0.331  Q=0.500
evolved_target40  (H1 模块化)  k=2  d=0.326  Q=0.496
```

**两个拓扑在结构上几乎完全相同（k、密度、模块度 Q 全部在 0.01 以内），判定却相反。**
这意味着：**任何只依赖这些结构量的预测器，都不可能同时判对这两个**——
26/27 的那"1 个错"是**结构性下限**，不是特征选得不好。

### 3.4 线性模型同样无效

`modularity_q + spectral_radius` 的线性拟合：**样本内 R² = 0.150**，
判定准确率 25/27（= 基线）。结构只解释了隔离强度方差的 **15%**。

## 四、结论（负结果）

> **纯结构预测故障隔离：不成立。**
> 结构特征最多把准确率从 25/27 提到 26/27（1 例），且该例是**结构性不可分辨**的。
> 结构只解释隔离强度方差的 15%。

### 为什么必然失败（机制解释）

`FAULT_ISOLATION_REPORT.md` 的判据是 **R² 降幅**。而 R² 取决于：

```
隔离效果 = 结构（模块耦合稀疏度） × 任务（哪个模块承载读出）
```

delay=5 记忆任务由**特定模块**支撑。关停一个"任务无关"的模块几乎不掉分，
关停"任务关键"模块掉分严重——**这个差别是任务属性，不在接线图里**。
所以 `evolved_target200` 与 `evolved_target40` 结构相同、判定相反，
是因为它们在**任务对齐**上不同，而不是结构不同。

**结构是必要不充分条件。**

## 五、下一步（被本结果重新定向）

| 原计划 | 修正后 |
|---|---|
| 把隔离预测器做进 `topology_profile.py` | ❌ **不做**——不发布比基线只强 1 例的"预测器" |
| 用结构量预测隔离等级 | ✅ 改为：预测器必须包含**任务对齐特征**（模块是否在读出通路上 / 模块到读出的可达性） |
| 26/27 视为"预测器可用" | ❌ 26/27 相对基线 25/27 无统计意义（n=2 负例） |

**真正该做的实验**：给每个模块计算"到读出的结构可达性"（BFS 距离 / 是否在读出通路），
把它作为第 10 个特征重跑本脚本。若届时准确率仍停在 26/27，则该方向**彻底关闭**。

## 七、诚实边界

- 27 个拓扑里只有 **2 个负例**（1 H2 + 1 H3）——任何"阈值规则"都建立在 n=2 上，**不具统计意义**。
- 特征是**在密化后的矩阵上**算的（与实验一致），不是原始 organism。
- 判定阈值 ±0.05 沿用原实验；改动它会改变 H2/H3 计数。
- 本报告**不否定**"结构稳定性是真实护城河"（25/27 是实测），
  它否定的是"**不用跑动力学就能预测**它"。
